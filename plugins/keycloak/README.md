# Keycloak Plugin (Planned)

This directory is reserved for a future **Keycloak** integration for **mTOTP**.

The goal of this plugin is to explore how a manual, human-executable TOTP variant could be incorporated into Keycloak-based identity and access management workflows, such as custom authenticators or alternative second-factor mechanisms.

At present no implementation exists

This directory is intentionally empty and exists to indicate planned exploration only.

Design discussions, high-level proposals, and threat-model considerations are welcome, particularly those that respect both Keycloak’s architecture and mTOTP’s human-execution constraints.

Implementation work will be considered once the mTOTP specification reaches a stable baseline.
